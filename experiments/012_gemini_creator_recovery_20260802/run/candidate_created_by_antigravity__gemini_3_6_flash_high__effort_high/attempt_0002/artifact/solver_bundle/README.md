# RADN-Sim Solver Bundle

This folder contains all solver-visible files for the RADN-Sim benchmark:

- `SOLVER_MANIFEST.json`: Manifest describing the benchmark package.
- `items_private_sample.jsonl`: 30 evaluation items containing problem specifications.
- `solver_packet.md`: Complete microarchitecture specification, cycle clock phase ordering, opcode definitions, routing rule specifications, trace log formatting, and SHA-256 output format.

Refer to `solver_packet.md` for full implementation details to solve the items.
